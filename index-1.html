REST API LUMI expects

LUMI polls GET {address}/api/sensors and expects JSON. Any field may be null or omitted; LUMI shows "—" for missing values and never fills them in.

{
  "device": "ESP32-LUMI",
  "heart_rate": 72,
  "spo2": 98,
  "temperature": 36.5,
  "humidity": 48,
  "gas_status": "good",
  "gas_value": 120
}

The ESP32 must send Access-Control-Allow-Origin: * (CORS). An example Arduino sketch is included (esp32_lumi_sensor.ino), untested on hardware. See README for HTTPS / mixed-content limits.
